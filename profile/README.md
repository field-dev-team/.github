# 현장개발단

현장의 반복 확인 작업을 비전 AI와 웹으로 덜어 주는 팀입니다.
충청권 특화산업 연계 ICT 현장적용 프로젝트에 참여하고 있습니다.

## 지금 만드는 것

**의료기기 포장 적합성 검사 MVP**

포장하기 직전에 작업대를 찍으면, 제품·수출국가·거래처별 포장기준을 불러와
구성품·라벨·UDI가 기준과 맞는지 **적합 / 주의 / 부적합**으로 판정하고 근거를 보여 줍니다.
품질담당자는 현장에 가지 않고 화면에서 확인합니다.

- UDI(GS1 DataMatrix·QR) 판독으로 제품 식별
- 라벨 OCR과 도메인 키워드 사전 보정으로 제품명·LOT·유효기간·필수문구 확인
- 판정 근거(기대값·실제값·사진 위 위치)와 검사 이력

기준·라벨 데이터는 모두 가상이며, 실제 의료기기 적합성을 보증하는 도구가 아닙니다.
